# Predicción de la calidad del agua
## Descripción:
Este parcial desarrolla un modelo de predicción de la calidad del agua utilizando técnicas de Machine Learning, apoyado en procesamiento distribuido con PySpark. El objetivo principal es estimar el Water Quality Index (WQI) a partir de variables fisicoquímicas, permitiendo identificar el estado del recurso hídrico de forma eficiente y escalable.
El flujo del parcial abarca desde la preparación de datos hasta la evaluación de modelos, integrando herramientas de análisis y aprendizaje automático para generar resultados precisos y confiables.

## Tecnologías usadas:
  - Python
  - PySpark (MLlib)
  - Keras / TensorFlow
  - Pandas / NumPy
  - Matplotlib / Seaborn
## Resultados:
  - El modelo de redes neuronales alcanzó una alta precisión en la predicción del WQI
  - Se evidenció una rápida convergencia durante el entrenamiento
  - Los resultados demuestran la capacidad del modelo para capturar relaciones complejas entre variables
